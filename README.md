## How to Preview Both Screens
This prototype uses static named routes in `lib/main.dart` without navigation logic:
- **Screen 1 (`ProfileScreen`):** Set `initialRoute: '/screen1'` in `lib/main.dart` (or navigate to `/#/screen1`).
- **Screen 2 (`ScheduleScreen`):** Set `initialRoute: '/screen2'` in `lib/main.dart` (or navigate to `/#/screen2`).
